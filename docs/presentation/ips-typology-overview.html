IPS — Investigative Priority Score

"Which connections should I investigate first?"
L1
Graph Topology — Betweenness centrality, temporal clustering, cross-type bridges, isolation anomalies. Computed from Neptune graph structure.
L2
Prosecutorial Pillars — The Act, The Means, The Network, The Pattern. Maps evidence to elements required for federal prosecution.
L3
AI Insight — Bedrock generates prosecutorial confidence score and narrative assessment for each detected pattern.
→ Output
Ranked list of investigative patterns scored 0-100.
"Marcus Blackwell ↔ 6 persons ↔ 3 locations" = IPS 78/100
🔴

Crime Typology — Pattern Recognition

"What type of criminal operation does this evidence suggest?"
1
Entity Analysis — Classifies entities by type (persons, victims, locations, financial, communications, venues) and maps to 6 trafficking categories.
2
Flag Detection — 30 typology flags across 6 categories. Each flag triggers on specific entity/relationship combinations (e.g., "structuring + controlled accounts").
3
Situation Clustering — Groups entities into detected "situations" — specific instances of a pattern with AI-generated investigative briefs.
→ Output
Case scored against 6 crime categories with drill-down into detected situations.
"Recruitment & Grooming: 72% — 4 situations detected"
