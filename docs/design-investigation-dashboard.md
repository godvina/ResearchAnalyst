# Design: Unified Investigation Dashboard

## The Problem
Currently we have:
- Pattern Library page (taxonomy browser with ley lines as one card)
- Grid Globe page (62 nodes with patterns/signatures sidebar)
- These are disconnected — no drill-down, no intelligence briefs on click, no network graph

## The Investigator's Mental Model

A Discovery Channel researcher thinks like this:

```
I got a theory (ley lines) 
  → Show me the evidence globally (grid map with all nodes)
    → I click a specific node (Giza)
      → Show me the AI intelligence brief for this site
        → What connects this site to others? (network graph)
          → What should I investigate next? (auto-recommendations)
```

This is ONE continuous flow, not 3 separate pages.

## Unified View Design

URL: `grid-globe.html` (becomes the primary investigation interface)

### Map Layers (toggleable)
1. **Grid Nodes** (62 color-coded points) — always on
2. **Documented Ley Lines** (named lines: St Michael's, Great Alignment, etc.) — toggle
3. **Network Graph Overlay** (connections between nodes sharing patterns) — on click
4. **Theoretical Grid** (faint Becker-Hagens triangles) — toggle

### Hover Behavior
- Hover any node → tooltip with site name (or "Node X (coordinates)" if unknown)
- Hover any connection line → tooltip showing what pattern connects the two endpoints

### Integration with Ley Lines Card
From the Pattern Library ley lines view:
- Add button: "🌐 View Full Grid Investigation"
- Clicking it opens grid-globe.html with ley lines layer pre-toggled ON
- The documented ley lines (St Michael's, Great Alignment) show as solid colored lines
- The grid nodes show which documented lines pass through/near them

### The Meta-Layer Insight
The grid globe becomes the UNIFYING VIEW for ALL typologies:
- Turn on "Advanced Technology" layer → nodes with precision machining light up
- Turn on "Lost Civilizations" layer → nodes with pre-flood architecture light up  
- Turn on "Sacred Geometry" layer → nodes with phi-ratio distances light up
- ALL of them cluster at the SAME grid nodes → proves the grid is the organizing principle

This is the Discovery Channel episode: "Every theory in ancient mysteries points to the same 62 locations."

## What Makes This Better Than Separate Pages
- ONE mental model: "I'm investigating a theory on a globe"
- Context never lost: clicking deeper reveals more, clicking elsewhere pivots
- The MAP is the organizing principle (geographic = intuitive)
- Network graph shows WHY things connect (not just that they're near each other)
- Recommendations drive the next click (investigator never gets stuck)
